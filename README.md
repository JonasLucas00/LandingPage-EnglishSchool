# Projeto Landing page English-School

Este projeto consiste em uma landing page simples sobre uma escola de inlglês ficticia.
Landing page foi estilizada com CSS e bootsrap.
Possui um form onde o usuario preenche email e senha, e é enviado um 'ebook' de inglês
no email que ele inseriu.

> A landing page foi criada para prática de estilização com Bootstrap e CSS — não representa uma versão final para produção.

## 📦 Como executar o projeto

1. Clone o repositório:
```bash
git clone https://github.com/JonasLucas00/LandingPage-EnglishSchool.git
```

2. Acesse o diretório do projeto:
```bash
cd nome-do-projeto
```

3. Instale as dependências
```bash
npm install
```

4. Inicie o servidor:
```bash
npm run dev
```
